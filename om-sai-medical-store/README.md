# Om Sai Medical Store — Full-Stack Pharmacy

Frontend + Node/Express backend + SQLite database + JWT authentication + prescription upload/review + cart/orders + inventory + admin APIs.

## Run
npm install
npm run dev
Open http://localhost:3000

Default admin email is admin@omsai.local; set ADMIN_PASSWORD in .env before use.

Before production, connect a real payment gateway, email/SMS/WhatsApp provider, cloud storage, HTTPS/domain and complete Indian pharmacy/compliance review.
